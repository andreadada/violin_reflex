# 00 — Acquisizione

## Obiettivo

Ridurre i riflessi indesiderati sulla superficie del violino senza perdere colore, venature e dettagli autentici.

## Fotografie

| File | Illuminazione |
| --- | --- |
| `Base.tif` | Tutte e quattro le luci accese |
| `Riflesso_1.tif` | Solo luce 1 |
| `Riflesso_2.tif` | Solo luce 2 |
| `Riflesso_3.tif` | Solo luce 3 |
| `Riflesso_4.tif` | Solo luce 4 |

- Risoluzione: **5504 × 8256 px** (circa 45,4 MP).
- TIFF RGB utilizzati per la registrazione: **8 bit per canale**.
- `Base.tif` è il riferimento geometrico.

## Vincoli operativi

- Non modificare o sovrascrivere i TIFF originali.
- Misurare sugli originali a pixel nativi; ridimensionare soltanto le anteprime.
- Non confondere variazioni di luce e disallineamenti.
